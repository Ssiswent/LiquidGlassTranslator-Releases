Installation & updates

Open the DMG, drag LiquidGlassTranslator to Applications, wait for copying to finish, eject the disk image, then launch it from Applications. These releases use Ad Hoc signing and are not notarized by Apple. If macOS blocks the first opening, use the normal Open Anyway option in Privacy & Security after reviewing the app. Do not disable Gatekeeper. Automatic update checks and downloads are off; use the app’s manual Check for Updates command.
