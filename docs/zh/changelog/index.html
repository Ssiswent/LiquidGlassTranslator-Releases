稳定版 · Stable

0.1.3

Build 23 · 2026-11-06

LiquidGlassTranslator 0.1.3 (Build 23) — 稳定版 本次改进 - 扩展对各类 macOS 应用的选词兼容性：优先通过辅助功能读取文字，无法获取时再尝试有界的剪贴板回退。成功取得并验证的文字会直接开始翻译，无需再按一次翻译按钮。 - 剪贴板回退会尽最大努力恢复此前的内容，包括常见的纯文本、富文本、图片与文件表示；恢复不是跨进程原子操作，无法保证所有并发场景下绝对无损。 - 包含 0.1.3 Beta 系列中已改进的原生设置界面行布局、图标对齐和滚动位置恢复。 - 保留手动 Sparkle 检查更新；自动检查和自动下载更新仍保持关闭。 重要升级说明 - 从 0.1.3-beta.4 开始，Provider API Key 与 ChatGPT 登录凭据改由本地加密 Vault 保存。从 0.1.2 升级后，需要重新输入 OpenAI Compatible、DeepSeek、Gemini API Key，并重新登录 ChatGPT。旧 Keychain 项目不会被导入或删除；非敏感设置和翻译历史继续使用原有存储。 - 部分应用即使没有高亮选中文字，也可能复制整条消息。如果回退机制校验通过，LGT 可能自动将该消息发往当前选定的翻译 Provider。 - 第三方剪贴板历史软件可能记录临时复制；并发写入和特殊延迟数据提供者可能妨碍完整恢复，或带来瞬时内存占用。 兼容性：Apple 芯片（arm64），macOS 26.0 或更高版本。
