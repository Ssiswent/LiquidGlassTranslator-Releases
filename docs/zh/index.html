安装与更新

打开 DMG，将 LiquidGlassTranslator 拖入 Applications 文件夹，等待复制完成后弹出磁盘映像，再从 Applications 启动。此发行版使用 Ad Hoc 签名且未经 Apple 公证。如果 macOS 阻止首次打开，请确认应用来源后，在「隐私与安全性」中使用系统提供的「仍要打开」选项。无需关闭 Gatekeeper。自动检查和下载更新保持关闭，可在应用中手动检查更新。
